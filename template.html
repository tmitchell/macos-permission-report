How to revoke

tccutil reset All <bundle-id> only works while the app is installed: tccutil looks the bundle ID up in LaunchServices and fails with No such bundle identifier (OSStatus -10814) for uninstalled apps. That leaves two options:

  • Targeted: reinstall the app, run tccutil reset All <bundle-id> with the ID shown above, then uninstall it again.
  • Per service: reset each affected permission for every app. Apps you still use will ask again the next time they need access, so you re-grant the ones you want. This also clears path-based entries. Resetting system-level permissions (Full Disk Access, Accessibility, Screen Recording, Input Monitoring) may require sudo.
